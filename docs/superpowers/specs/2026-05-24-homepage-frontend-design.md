# Realis 首页前端设计记录

## 当前定位

首页采用“安静旅宿票据 + 情绪音频卡片”的视觉方向。它不是传统营销页，而像用户进入一个私密房间前收到的一组入住凭证：顶部清晰导航，左侧为可交互的情绪音乐卡组，右侧解释产品价值并提供主要入口。

## 版式结构

顶部导航固定在页面上方：

- 左侧显示 `Realis / 返照` 品牌标识。
- 中间显示页面导航：首页、AI觉察、记忆画廊、人际罗盘。
- 右侧显示语言入口和登录按钮。

主体为两栏布局：

- 左侧是三张实体卡片组成的音乐卡组。
- 右侧是网站简短介绍、登录入口，以及 AI觉察、记忆画廊、人际罗盘三个页面入口。

底部保留三段辅助说明：记录具体事件、进入 AI 信号室、沉淀为安静档案。

## 左侧音乐卡组

音乐卡组由三张不同材质的实体卡组成：

- 黑色音频卡：模拟声音输入、频率和播放状态。
- 红棕色卡：像一张温暖的记录卡，显示下一段情绪信号。
- 米色票据卡：像入住凭证，承载未来回看的隐喻。

交互规则：

- 点击最前面的卡片：切换播放 / 暂停状态。
- 拖开最前面的卡片：下一张实体卡补到前面。
- 双击后面的卡片：该卡片直接提到前面。
- 鼠标滚轮：快速切换上一张或下一张。

卡片轮换是实体层级循环，而不是复制三张黑色音乐卡。切换顺序为：

1. 黑色卡在前，红棕卡在中，米色卡在后。
2. 红棕卡在前，米色卡在中，黑色卡在后。
3. 米色卡在前，黑色卡在中，红棕卡在后。

## 视觉语言

整体颜色保持温润克制：

- 背景：米白纸感。
- 强调色：红棕、浅金、墨黑。
- 质感：轻微纸张阴影、票据边框、柔和径向光。

字体策略：

- 品牌和标题使用当前项目的衬线字体气质。
- 功能说明和导航使用 `font-sans-soft`，保持现代产品可读性。
- 音频卡和票据细节使用等宽字体，形成“信号 / 凭证”的机械感。

## 当前约束

- 暂不实现真实音频文件播放。
- 播放按钮只表示前端播放状态。
- 歌曲卡片的歌单和切换逻辑将由轻量后端接口提供，便于后续替换为真实音频、用户个性化歌单或 Supabase 存储。
