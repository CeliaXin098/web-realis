# AI 觉察单卡片流程与自我罗盘设计

## 目标

让 AI 觉察从“左右两张并列卡片”变成一张可以在准备、对话、觉察信之间完全切换的大卡片，并让人际罗盘中心的“我自己”成为可查看、可维护的自我关系档案。

## AI 觉察流程

### 完全切换单卡片

- 初始状态展示觉察准备：具体事件、情绪、相关人物、情绪强度与安全提示。
- 点击“开始与 AI 深度对话”后，同一张卡片切换为全宽对话视图，不再同时显示准备表单。
- 对话视图使用更大的正文字号，并提供“返回补充信息”按钮。
- 生成的觉察信继续在同一张卡片中展示，超出卡片高度时内部滚动。
- 右侧觉察日历、今日摘要与时间轴保持独立。

### 新一轮觉察

- 生成觉察信后显示“开始新一轮觉察”。
- 保存到记忆画廊后继续保留该按钮。
- 点击后清空具体事件、情绪、强度、相关人物、聊天输入、对话、觉察信、保存状态和本地草稿。
- 已经保存到数据库和记忆画廊的历史记录不受影响。

## MBTI 规则

- AI 推断的 MBTI 只保留最可能的一个四字母类型，例如 `INFP（推测）`。
- 不显示多个候选，也不把长段人格描述塞入 MBTI 输入框。
- 用户手动修改并自动保存后，存为四字母类型，例如 `INFP`，不再显示“推测”。
- 非法或无法识别的 AI 文本不作为 MBTI 类型展示。

## 自我关系档案

### 中心头像交互

- 点击人际罗盘中心“我自己”头像后，右侧切换到自我关系详情。
- 自我详情不使用普通人物的关系温度、Tier、象限和“我们的故事”。
- 再点击其他人物，恢复普通人物详情与故事。

### 自我详情内容

- MBTI：来自用户长期记忆档案。AI 推断时显示“（推测）”，用户修改保存后去掉推测。
- 荣格八维：综合全部觉察记录中的 `jungian_functions`，按功能代码聚合展示。
- 外在表现：从长期记忆中的反复模式与支持方式提炼。
- 内心需要：来自长期记忆中的核心需要。
- 自我接纳度：根据记录中的自我支持、自我否定和需要被看见等线索形成温和指标。
- 内外一致度：根据外在表现与核心需要的贴合程度形成温和指标。
- 常见内在冲突：来自反复模式、触发点与需要之间的张力。
- 照顾自己的建议：基于支持方式和核心需要生成，不做人格定论或医学诊断。

## 数据设计

- `user_memory_profiles` 增加：
  - `mbti_type text not null default ''`
  - `mbti_source text not null default 'inferred'`
  - `jungian_functions jsonb not null default '[]'`
- `mbti_source` 只允许 `inferred` 或 `confirmed`。
- 每次保存觉察时，聚合自我 MBTI 与荣格八维线索到长期记忆档案。
- 用户手动保存自我 MBTI 时，将来源改为 `confirmed`，后续 AI 推断不覆盖确认值。

## 错误与空状态

- 没有足够自我记录时，中心头像仍可点击；详情使用“还需要更多觉察记录”的温和空状态。
- MBTI 无法从 AI 文本提取时显示空输入，不猜测类型。
- 新一轮重置只清除当前草稿，不删除任何历史数据。

## 验证

- 单元测试覆盖 MBTI 单值提取、推测/确认显示、确认值不被覆盖、自我指标与新一轮重置数据。
- API 测试覆盖自我档案读取和手动 MBTI 保存。
- 端到端测试覆盖单卡片完全切换、返回补充信息、完成后开始新一轮、中心头像自我详情和 MBTI 推测标签消失。
